# Sales & Profit Analysis Dashboard

## Project Overview

This project analyzes sales and profit data using Python to identify business performance trends, profitable product categories, regional sales distribution, and loss-making products. The analysis helps support data-driven business decisions through data cleaning, aggregation, and visualization.

## Tools & Technologies

* Python
* Pandas
* Matplotlib

## Dataset Features

* Order Date
* Product
* Category
* Sales
* Profit
* Region

## Project Workflow

### 1. Data Cleaning

* Removed duplicate records using `drop_duplicates()`
* Handled missing values using `fillna()`
* Converted Order Date into datetime format

### 2. Data Analysis

* Calculated Total Sales
* Calculated Total Profit
* Calculated Average Profit
* Analyzed Monthly Sales Performance
* Identified Highest Profit-Generating Category
* Detected Loss-Making Products
* Evaluated Regional Sales Distribution

### 3. Data Visualization

Created the following visualizations:

* Monthly Sales Trend (Line Chart)
* Profit by Category (Bar Chart)
* Regional Sales Distribution (Pie Chart)

## Key Insights

* Identified overall business revenue and profitability.
* Determined the most profitable product category.
* Highlighted products generating losses.
* Analyzed sales contribution across different regions.
* Tracked monthly sales trends to understand seasonal performance.

## Learning Outcomes
